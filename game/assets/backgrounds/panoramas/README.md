# 地形貼圖 / 全景背景素材說明

原有5張程式化生成的過渡佔位地形貼圖（`water_ground.png` 等，Perlin/fBm噪聲合成）
已於 2026-08-04 全部移除，改為採用 **AI 生成 + 手卷留白拼接** 的正式方案重新製作。

## 新方案：獨立分段生成 + 淡出宣紙白過渡

不追求 AI「無縫續畫」整張長卷（實測 outpainting/inpainting 在接縫處必然留下語意層級的
硬邊界，見專案技能 `ai-panorama-fade-transition` 的踩坑記錄），改用：

1. 針對每個關卡主題（水/火/木/土/終章祭壇）**獨立生成 2 段主題一致的水墨畫面**
   （`fal-ai/flux/dev`，2048×512，明確在 prompt 中排除題字/印章/文字元素）
2. 用 `game/data/palette.json` 的 `paper` 色 `[0.93, 0.90, 0.83]` 做淡出/淡入邊緣，
   中間留一段純宣紙色的間隔——手卷留白美學本來就讀作「藝術性停頓」而非拼接瑕疵
3. 固定參數：`fade_width=280px`、`gap_width=100px`、`smootherstep` 緩動曲線
   （這是與用戶反覆核對過6輪的定案值，不要再改）

沿用專案既有的視差循環邏輯（`ink_parallax.gd`，`repeat_times=3`）——這批全景圖
**不需要跟關卡實際像素長度1:1對應**，只需要「夠長、循環點不會太快讓人感覺重複」即可。
待 Task 4.1/4.2 等關卡場景實際建成、有精確像素長度後，可視需要升級為關卡等長的
單一全景圖（見下方「後續」）。

# 劇情道具圖標素材說明

本目錄的6張劇情道具圖標是**程式化生成的過渡佔位圖**，不是神經網路AI繪圖
模型的產物——當前環境沒有配置任何可用的圖像生成API，因此改用Pillow+NumPy
手寫的水墨渲染引擎合成（毛筆筆觸模擬/宣紙紋理/墨韻字形渲染），嚴格複用
`game/data/palette.json`色板與專案字型`LXGWWenKaiTC-Regular.ttf`。

## 規格

- 768×512px，PNG（RGBA，背景為宣紙色滿鋪，非透明）
- 用於場景內可互動物體/場景裝飾（Sprite2D）

這批圖是**臨時佔位資源**，用於驗證場景內道具擺放與敘事節點觸發邏輯，
不代表最終上線品質。正式美術資源應優先考慮接入真正的圖像生成API重新

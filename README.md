# 部首闯字 (Hanzi Runner) — working title

繁体汉字横版闯关游戏，类似合金弹头(Metal Slug)。核心机制：主角/敌人以渲染汉字呈现，武器来自汉字部首拆解，五行相生相克驱动伤害平衡。

## 项目状态

🚧 规划阶段 — 引擎已定案，7天开发计划已完成，尚未开始编码。

## 核心玩法

| 部首 | 五行 | 武器类型 | 克制 |
|---|---|---|---|
| 氵/水 | 水 | 水波/范围减速 | 克火 |
| 火/灬 | 火 | 火球/喷射AOE | 克金 |
| 钅/金 | 金 | 利刃/高攻速暗器 | 克木 |
| 木 | 木 | 藤蔓/控制刺击 | 克土 |
| 土 | 土 | 撞击/防御反弹 | 克水 |

Boss为复合字（淼/焱/森），拆解出多个部首子武器，多阶段战斗。
